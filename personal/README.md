## 디자인 규칙

"이른 아침의 바닷가". 더하지 말고 빼는 방향. 새 요소를 만들 때도 이 선을 넘지 않는다.

| 역할 | 값 |
|---|---|
| 배경 | `#FAFDFD` |
| 본문 | `#1A2E35` |
| 보조 | `#5C7A85` |
| 포인트 | `#0E7C94` — 링크와 CTA에만, 화면의 5% 이하 |
| 구분선 | `#E4EFF1` |

- 서체는 Pretendard. 헤드라인 600 / `letter-spacing: -0.02em`, 본문 16px / `line-height: 1.7`
- 콘텐츠 폭 1080px, 좌우 24px, 섹션 간격 데스크톱 140px · 모바일 80px
- 반경은 카드 8px, 버튼 6px. **알약형(9999px) 금지**
- 그림자는 `0 1px 3px rgba(26,46,53,.06)` 하나만
- **그라데이션·이모지·글로우·글래스모피즘 금지.** 아이콘도 꼭 필요할 때만
- hover는 `0.2s ease`로 색이 조금 깊어지는 정도. 확대·바운스 없음
- 스크롤 등장은 `.rise` 클래스 하나(opacity + 8px, 1회)로 통일

새 색을 추가하기 전에 이 다섯 개로 표현할 방법이 없는지 먼저 확인할 것.
데이터(JSON)에도 이모지를 넣지 않는다 — 페이지가 그대로 렌더링한다.

## 구례 페이지 (종료)

**2026-10-04 대회 완주 — 14:37:45** (수영 1:38:33 · 바이크 6:56:53 · 런 5:35:39, M30-34 60/71, 잠정 기록).
세 페이지는 종료된 프로젝트로 표시하고 **대회 전 계획 그대로 보존**한다. 기록과 구간 분석(수영 바퀴·바이크 구간·런 바퀴·컷오프 여유)은 `exercise.html#result`,

`gurye_course.html`과 `gurye_fuel.html`은 `assets/gurye.js`의 `GURYE.simulate()`로 시계 시각을 계산한다.
시뮬레이터 설정은 localStorage `gurye.sim.v1`에 저장되고 보급 페이지가 그대로 읽는다(보급 페이지에는 슬라이더 없음).
백 체크리스트는 `gurye.pack.v1`. 거리·컷오프·보급소 품목의 출처는 `data/gurye/SOURCE.md`.

`gurye_geo.js`는 엑셀 랜드마크 사이를 OSRM(OSM 도로망)으로 이어 엑셀 누적 km에 매핑한 뒤 Open-Meteo(Copernicus DEM 90m)로 고도를 붙인 것. 공식 GPX가 나오면 같은 형식 `[km, lat, lon, elev]`으로 교체하면 지도·프로파일·언덕 표가 그대로 따라온다.

## 근력 페이지

`strength.html`은 구례 훈련 캘린더(`exercise.html`)와 같은 형식 — 월별 달력, 날짜를 누르면 아침·저녁 운동 팝업.
2026-10-08 ~ 2027-02-28. 평일 아침 헬스장 근력 네 동작(화 로잉 · 목 러닝 추가), 월·수 저녁 수영, 토 평로라, 일 롱런.
팝업 아래에 헬스장을 못 가는 날을 위한 맨몸 대체 목록이 붙는다.

- 동작 이름과 맨몸 대체는 `EX`, 맨몸 처방이 다른 것은 `ALT_RX`
- 요일별 처방은 `W[단계][요일]` (`s` 근력 · `c` 유산소 · `alt` 맨몸 대체 유산소)
- 단계 기간은 `PHASES`, 가볍게 주는 `LIGHT`(세트 2개 · 유산소는 `LIGHT_C`), 공휴일은 `HOLIDAYS`
- 설명·테스트·체크 기능은 일부러 넣지 않는다. 운동 내용만.

### 토요일 이지 러닝 · 저녁 집 운동 · 부산 여행 (2026-11-23)

- **토요일**: 평로라를 타지 않아 2026-11-23부터 이지 러닝으로 바꿨다(`SAT_RUN_FROM`, `SAT_RUN` — 기초 30분 · 빌드·피크 40분 · 테이퍼 25분, 디로드 주 25분). 그 전 토요일은 평로라 그대로 남는다. 12/5는 10km 측정 전날이라 20분 + 마무리 가속.
- **화·목·금 저녁 집 운동**: 푸시업 바 기준 15분(`HOME`, `HOME_FROM`). 화 밀기 · 목 코어·골반 · 금 밀기 + 버티기. 다리는 쓰지 않는다. 디로드·테이퍼는 세트 2, 대회 주와 여행일은 쉰다. 팝업의 「저녁」 칸과 목록 블록, 달력 점(`home`)으로 보인다.
- **부산 여행 12/23~28**: `TRIP`에 여섯 날. 야외 러닝 위주(수 이지 50 · 목 마라톤 페이스 8km · 금 이지 30 · 토 휴식 · 일 롱런 130분 · 월 귀가 휴식), 근력·집 운동·수영은 쉬고 만회하지 않는다. `TRIP`이 롱런(`long`)과 롱런 후 스트레칭(`post:'LONG'`)을 받게 했다. 코스는 여행 계획이 잡히면 다시 적는다.
- 주간 러닝 거리가 토요일만큼 늘었다(최대 주 약 86km, W21).

### 11/15 손기정 풀코스 코스 팝업

`strength.html`에서 11/15(대회일)을 누르면 「코스 · 보급」 칸과 **코스 분석 · 보급 전략** 버튼이 있다. 팝업 내용: 공식 코스도, 거리·누적 고도·예상 완주, 고도 프로파일(SVG, 젤 위치·언덕 표시), 구간별 계획(고도·바람·페이스·누적), SiS 젤 계획표, 날씨, 아직 확인 못 한 것.

- 데이터: `data/sohn_course.js`(`window.SOHN` — 0.2km 간격 고도, 랜드마크 km, 언덕 정상, 구간 통계, 날씨). 지도: `../assets/img/sohn/course-2026.jpg`(공식 코스도 1400px)
- **거리**는 코스도의 빨간 선을 이미지에서 따라 그렸다. 출발 → 마정교차로 → 1차 반환(도라산역 톨게이트) → 마정 → 여우고개 → 2차 반환(리비삼거리) → 마정 → 도착의 왕복 구조이고(화살표 방향으로 확인), 42.195km 인증 거리에 축척을 맞췄다(151.8px/km). 마정교차로·여우고개사거리·통일대교의 실제 좌표와 0.1~0.2km 안에서 맞는다
- **고도**는 Copernicus DEM 90m(Open-Meteo)를 100m 간격으로 읽어 ±0.4km 이동평균. 누적 상승·하강 +176/−176m는 평활 범위에 따라 120~175m로 달라지고 오차 ±30%로 본다. 사실상 평탄하고 언덕은 여우고개 한 곳(17~19.6km, 돌아올 때 34~36km)
- **날씨**는 Open-Meteo ERA5 2016–2025년 11월 15일 파주 평균
- **공식 급수대 위치·품목, 민통선 입장 규정, 정확한 출발 시각은 확인하지 못했다.** 확인되면 `openCourse()` 안의 `PL`(구간 계획)과 `FUEL`(젤 계획)을 고친다. 젤 1개는 22g으로 계산(`GEL`, 구례 계획과 같은 값)
- 구간 페이스(`PL`의 3번째 값)를 바꾸면 하프·완주 예상과 젤 통과 시각이 같이 바뀐다
