## 디자인 규칙

"이른 아침의 바닷가". 더하지 말고 빼는 방향. 새 요소를 만들 때도 이 선을 넘지 않는다.

| 역할 | 값 |
|---|---|
| 배경 | `#FAFDFD` |
| 본문 | `#1A2E35` |
| 보조 | `#5C7A85` |
| 포인트 | `#0E7C94` — 링크와 CTA에만, 화면의 5% 이하 |
| 구분선 | `#E4EFF1` |

- 서체는 Pretendard. 헤드라인 600 / `letter-spacing: -0.02em`, 본문 16px / `line-height: 1.7`
- 콘텐츠 폭 1080px, 좌우 24px, 섹션 간격 데스크톱 140px · 모바일 80px
- 반경은 카드 8px, 버튼 6px. **알약형(9999px) 금지**
- 그림자는 `0 1px 3px rgba(26,46,53,.06)` 하나만
- **그라데이션·이모지·글로우·글래스모피즘 금지.** 아이콘도 꼭 필요할 때만
- hover는 `0.2s ease`로 색이 조금 깊어지는 정도. 확대·바운스 없음
- 스크롤 등장은 `.rise` 클래스 하나(opacity + 8px, 1회)로 통일

새 색을 추가하기 전에 이 다섯 개로 표현할 방법이 없는지 먼저 확인할 것.
데이터(JSON)에도 이모지를 넣지 않는다 — 페이지가 그대로 렌더링한다.

  (`aspect-ratio` 지정)

  GIF를 바꾸려면 JSON과 HTML을 함께 고칠 것

**한 섹션에 하나, 페이지당 셋까지.** (여행 페이지만 예외 — 요청에 따라 섹션·일정마다 하나씩, 출처 섹션 끝에는 세 개를 나란히 둔다. 같은 `gromit.json` 목록에서 골라 HTML에 직접 쓴다.) 넷째를 넣고 싶어지면 대신 기존 하나를
빼는 게 맞다. 새로 고를 때는 `giphy.com/wallaceandgromit`(공식 채널)에서만
가져오고, 실제로 열어 본 뒤 `alt`를 장면 그대로 적는다.

**HTML은 이 폴더 최상단에 고정한다.** 홈화면에 설치된 바로가기가 URL로 물려
있어서 파일을 옮기면 전부 깨진다.

### 11/15 손기정 풀코스 코스 팝업

`strength.html`에서 11/15(대회일)을 누르면 「코스 · 보급」 칸과 **코스 분석 · 보급 전략** 버튼이 있다. 팝업 내용: 공식 코스도, 거리·누적 고도·예상 완주, 고도 프로파일(SVG, 젤 위치·언덕 표시), 구간별 계획(고도·바람·페이스·누적), SiS 젤 계획표, 날씨, 아직 확인 못 한 것.

- 데이터: `assets/sohn_course.js`(`window.SOHN` — 0.2km 간격 고도, 랜드마크 km, 언덕 정상, 구간 통계, 날씨). 지도: `assets/sohn/course-2026.jpg`(공식 코스도 1400px)
- **거리**는 코스도의 빨간 선을 이미지에서 따라 그렸다. 출발 → 마정교차로 → 1차 반환(도라산역 톨게이트) → 마정 → 여우고개 → 2차 반환(리비삼거리) → 마정 → 도착의 왕복 구조이고(화살표 방향으로 확인), 42.195km 인증 거리에 축척을 맞췄다(151.8px/km). 마정교차로·여우고개사거리·통일대교의 실제 좌표와 0.1~0.2km 안에서 맞는다
- **고도**는 Copernicus DEM 90m(Open-Meteo)를 100m 간격으로 읽어 ±0.4km 이동평균. 누적 상승·하강 +176/−176m는 평활 범위에 따라 120~175m로 달라지고 오차 ±30%로 본다. 사실상 평탄하고 언덕은 여우고개 한 곳(17~19.6km, 돌아올 때 34~36km)
- **날씨**는 Open-Meteo ERA5 2016–2025년 11월 15일 파주 평균
- **공식 급수대 위치·품목, 민통선 입장 규정, 정확한 출발 시각은 확인하지 못했다.** 확인되면 `openCourse()` 안의 `PL`(구간 계획)과 `FUEL`(젤 계획)을 고친다. 젤 1개는 22g으로 계산(`GEL`, 구례 계획과 같은 값)

- 시험일과 체크 상태는 localStorage(`dsLv3.exam.v1`, `dsLv3.chk.v1`)에만 저장된다. 시험일을 넣으면 6주 계획에 주차별 날짜가 붙는다

## 허브의 「종료」 그룹

`index.html` 맨 아래 「종료」(끝난 프로젝트)는 기본으로 접혀 있고, 왼쪽의 「N개 보기」를 누르면 펼쳐진다
(`grid-template-rows 0fr → 1fr`, 접힌 동안은 `inert`). 버튼의 개수 문구는 `.row` 수로 JS가 계산하므로(HTML의 초기 값은 첫 화면용) 항목만 추가하면 된다. 끝난 프로젝트는 행에 `done` 클래스를 붙여 이 그룹에 넣는다.

## 상단 내비(빵부스러기)

모든 페이지 머리에 `ttomstudio / 섹션`이 있다. `ttomstudio`는 사이트 첫 화면(`../index.html`), 섹션 이름(Personal · Travel · Portfolio · food · CS)은 그 폴더의 `index.html`로 간다. 공통 마크업은 `<span class="crumb"><a class="home">…</a><span class="sep">/</span><a class="brand">…</a></span>`이고 스타일은 `assets/summer.css`(`.nav .crumb`)에 있다. 모바일(560px 이하)에서는 첫 줄에 빵부스러기, 둘째 줄에 페이지 링크가 놓인다.
자체 머리를 쓰는 페이지(`edge_study` · `steady_study` · `food/*` · `cs/*`)는 각자 스타일로 같은 링크를 넣었다. `cs/data_structure.html`은 번들 파일이라 문서 교체 직후(`replaceWith` 다음 줄)에 링크를 붙이는 코드를 넣었다 — 번들을 다시 내보내면 이 줄을 다시 넣어야 한다. 그로밋 아이콘(`gromit.css`)은 이제 `.nav .home`에 붙는다.
