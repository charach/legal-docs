두 번째 석사 · 무엇을 얻고 무엇을 못 얻나

아내와 같이 2027년 3월 입학. 결정은 끝났고, 남은 건 이 2년을 무엇으로 채우느냐다. 그러려면 대학원이 주는 것과 주지 않는 것을 정확히 갈라야 한다.

항목대학원이 주나그래서
아내와 같이 보내는 2년준다 — 이게 1순위 이유같은 학교·같은 학기를 맞추는 게 학교 선택의 제약이 된다
인맥 · 리퍼럴 경로준다 — 동기가 전부 직장인이직 계획에서 서류 통과 1순위로 꼽았던 리퍼럴을 콜드 메시지 없이 얻는다
강제 커리큘럼 · 페이스준다 — 학점과 마감이 있다혼자 하는 계획이 3주 연속 무너지던 문제를 구조로 푼다
교수 · 산학 연결학교·연구실마다 다름입학 후 첫 학기에 확인. 프로젝트 트랙 운영 방식을 물어볼 것
채용 신호로서의 학위거의 없다이미 CS 석사 보유 + 직접 조사한 공고에서 개발 트랙 석사 필수 0건
공고가 요구하는 스택RAG·Agent·LangGraph·Evals·vLLM·GPU 스케줄링안 준다특수대학원 커리큘럼은 기초 ML·DL·통계 중심 → 이 로드맵이 존재하는 이유

결론 — 인맥은 진짜고, 커리큘럼은 대체재가 아니다. 그래서 이 페이지는 대학원과 경쟁하지 않는다. 수업이 채우지 않는 칸만 골라서, 재학 2년의 학기·방학 리듬 위에 얹는다. 졸업할 때 남는 것이 학위 하나가 아니라 돌아가는 시스템 하나가 되게 하는 게 목표다.

「밑바닥」 시리즈 · 어디까지 갈 것인가

이어지는 책이 아니라 각각 다른 산이다. 5권 완독은 성취감은 주지만 능력 곡선은 2편 이후 급격히 평평해진다. 5권 읽기보다 2권 구현이 낫다.

권내용판단
1신경망·역전파·CNN, NumPy 직접 구현완주 ✓ 토대
2word2vec → RNN/LSTM → seq2seq → 어텐션(8장)계속. 단 8장이 본체 — 앞은 역사로 통과
3프레임워크 자작 (DeZero, 자동미분 60단계)보상용. 8년차 시스템 엔지니어에겐 가장 빨리 읽히지만 채용 신호는 약함
4강화학습 (밴딧·MDP·Q러닝·DQN)우회로. 고전 RL이라 RLHF/PPO/DPO와는 다른 세계
5이미지 생성 모델 (VAE·확산모델)멀티모달로 틀 때만

이 시리즈는 읽는 책이 아니라 치는 책이다. 2권 8장을 읽고 어텐션을 NumPy로 다시 짜는 데 쓴 3주가, 3·4·5권을 훑는 3개월보다 남는 게 많다.

재학 1년차 — 학기는 수업, 방학은 서빙

직장 + 대학원 + 개인 학습을 동시에 굴리면 셋 다 무너진다. 학기 중엔 수업이 우선이고 개인 학습은 주 3시간으로 낮춘다. 대신 여름·겨울 방학 각 8주를 서빙 레이어에 통째로 쓴다 — 이 로드맵에서 가장 희소하고, 수업이 절대 가르쳐주지 않는 구간이다.

2-1 · 여름방학 — 추론 엔진 (2027.07–08 · 8주)

Phase Ⅰ에서 직접 만든 모델을 GPU 위에 올려 레이턴시와 비용을 숫자로 통제한다. 여기가 이 로드맵의 핵심 차별점 — RAG 프로젝트 한 사람은 많지만, CKA·CKAD를 들고 GPU 서빙까지 아는 8년차 시스템 엔지니어는 드물다.

2-2 · 겨울방학 — K8s의 GPU 절반 (2028.01–02 · 8주)

CKA·CKAD로 이미 아는 영역 위에 GPU만 얹는다. 처음부터 배우는 게 아니라 빈칸을 채우는 작업이라 속도가 빠르다.

비용 주의. GPU 시간은 유일하게 돈이 드는 구간인데, 마침 학비가 나가는 시기와 겹친다. 클라우드 스팟 + 소형 모델로 시작하고 실험 스크립트를 먼저 짜서 띄운 시간을 짧게 가져간다. 방학당 예산 상한을 정해두고 시작할 것. 학교 GPU 서버 사용 가능 여부를 첫 학기에 확인하면 이 비용이 0이 될 수도 있다.

2-3 · 인맥 — 재학 중 상시

재학 2년차 — 졸업 프로젝트가 곧 포트폴리오

여기가 이 계획에서 가장 큰 절약이다. 석사 졸업 프로젝트와 개인 포트폴리오를 하나로 합친다. 따로 하면 2년치 일이고, 합치면 한 번이다. 주제는 법령·규정 QA 에이전트를 Phase Ⅱ에서 구축한 자체 서빙 스택 위에 올리는 것.

원칙

  • 졸업 프로젝트 = 포트폴리오 = 시스템 디자인 인터뷰 답안. 세 개를 따로 만들지 않는다. 지도교수와 주제를 정할 때 이 점을 염두에 두고 학술적 기여와 공고 요구사항이 겹치는 지점을 고른다.
  • 프로젝트는 딱 하나. 여러 개 벌리지 않는다.
  • 먼저 직접 구현 → 그다음 LangGraph로 재구현, 둘 다 한다. 인터뷰 만점 답변 = "리트리버를 직접 짜며 X 때문에 Y로 설계했고, 프로덕션은 LangGraph로 옮기며 트레이드오프를 이렇게 봤다".
  • Claude Code 등 AI 도구 사용 OK. 단 철칙 — 각 컴포넌트를 화이트보드에 그려 남에게 설명할 수 있을 때까지 다음으로 넘어가지 않는다.
  • 모델은 Phase Ⅱ의 자체 서빙 스택에서 가져온다. 상용 API는 품질 비교용 기준선으로만 — "자체 서빙 대비 상용 API의 품질·비용 차이"가 그 자체로 논문 한 절이자 블로그 글 하나다.

공고에서 역산한 요구사항

2026.07 기준 타겟 9개사 + 인접 스타트업의 실제 채용 공고를 직접 열어 뽑은 요구사항이다. 이 표가 위 네 단계의 설계 근거 — 각 항목은 "하면 좋아서"가 아니라 "이 공고가 요구해서" 존재한다. 대학원 커리큘럼이 이 표를 채워주지 않는다는 것이 Phase Ⅱ·Ⅲ가 존재하는 이유이기도 하다. 공고는 빠르게 바뀌므로 실제 지원 시점(2029)에 반드시 재수집.

학위 불안, 데이터로 종결. 직접 열어본 개발·애플리케이션 트랙 공고에서 석사를 필수로 요구한 곳은 0건이다. 업스테이지 AI Agent Engineer는 명시적으로 "학력 무관", 백엔드·플랫폼·Document AI·데이터 공고 모두 학위 요건 미기재. 석사가 필수인 것은 전문연구요원·파운데이션 모델 리서치 트랙(논문 실적 요구)뿐이다. 학위도 자격증도 요건이 아니고, 실물 포트폴리오가 그 자리를 대신한다 — 즉 Phase Ⅱ·Ⅲ의 산출물이 곧 대체재.

마지막 리마인더

지금 가장 중요한 마감은 11월 원서다. 학습 로드맵이 재밌어 보여도 Phase 0가 밀리면 입학이 1년 밀리고, 아내와 같은 학기라는 전제 자체가 깨진다. 10월 말까지는 서류가 학습보다 우선이다.

학기 중에 무리하지 않는 것이 계획의 일부다. 직장 + 대학원 + 개인 학습을 동시에 최대로 굴리면 셋 다 무너진다. 이 로드맵의 무거운 구간은 전부 방학에 배치돼 있고, 그건 실수가 아니라 설계다.

졸업 프로젝트와 포트폴리오를 따로 만들지 말 것. Phase Ⅲ의 전제가 이것 하나다. 지도교수와 주제를 정하는 순간에 이 결정이 내려지므로, 2학기(2027년 하반기)에 주제를 탐색할 때 미리 염두에 둔다.

자격증을 새로 알아보고 싶어질 때 이 문장을 읽을 것. 이미 확인했다 — 공고에 나오는 자격증은 쿠버네티스뿐이고 그건 이미 갖고 있다. 새 자격증을 찾는 시간은 vLLM을 한 번 띄워보는 시간과 맞바꾸는 게 항상 낫다.
