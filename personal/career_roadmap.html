모델 레이어 기초

"모델을 모른다"는 갭을 해소하고, 트랜스포머·학습 원리를 밑바닥부터 설명할 수 있는 상태를 만든다. 동시에 "외부 강제 없이 꾸준히 하는 사람인가"를 데이터로 검증한다.

주간 시간 설계 · 주 5–6시간

요일시간내용
토요일 오전3h (고정 09–12시)메인 학습 블록 — 강의 시청 + 코드 구현
평일 2회각 1–1.5h복습·재구현 (영상 안 보고 같은 코드 다시 짜기)

토요일 블록은 장소를 집 밖으로 — 카페·스터디카페. 평일이 무너져도 토요일만 지키면 실험은 유효하다. 토요일이 3주 연속 무너지면 그게 신호다.

커리큘럼 · Karpathy "Zero to Hero" — 통과 기준을 체크

진도보다 통과 기준. 1강에 3주 걸려도 무방하다. 목적은 완주가 아니라 "설명 가능한 상태".

강제장치 실험 · 12주 후 판정

결과판정
10주 이상 성공혼자 가능. 대학원 불필요 확정 → Phase 2 진행
6–9주절반 성공. Phase 2를 유료 스터디·커뮤니티와 병행
5주 이하외부 강제 필요. 특수대학원·부트캠프 재검토 (LLM 실습 비중 큰 곳만)

딥 프로젝트 하나

프로젝트는 딱 하나. 프레임워크(LangChain·LlamaIndex) 없이 직접 구현한다. 각 컴포넌트를 화이트보드로 설명할 수 있을 때까지 다음으로 넘어가지 않는다.

원칙

  • 프로젝트는 딱 하나. 여러 개 벌리지 않는다.
  • Claude Code 등 AI 도구 사용 OK. 단 철칙 — 각 컴포넌트를 화이트보드에 그려 남에게 설명할 수 있을 때까지 다음 컴포넌트로 넘어가지 않는다. AI가 짠 코드에서 비효율·오류를 최소 1개씩 직접 찾아 수정하고 커밋 메시지에 기록한다.
  • 프레임워크(LangChain·LlamaIndex) 없이 직접 구현. 이유 — 인터뷰에서 "LangChain 썼어요"는 0점, "리트리버를 직접 짜면서 X 때문에 Y로 설계했어요"는 만점.

업스테이지 (Upstage)

★ 최우선 추천
무엇을 하나
자체 LLM '솔라(Solar)' 개발 + Document AI(OCR·파싱). 금융·법률·제조 등 B2B 특화 AI 솔루션. 2025년 약 1,000억 원 시리즈B, 미국 시장 진출 추진.
왜 나에게 맞나
  • "해외로 나아가는 회사" + "모델 가까이에서 일하기" 조건을 동시에 충족하는 국내 거의 유일한 곳
  • B2B 엔터프라이즈 딜리버리 → 삼성에서의 대규모·엔터프라이즈 경험이 그대로 신뢰 자산
  • Document AI ↔ Samsung Notes·필기인식 경험이 도메인적으로 연결됨 (문서 이해라는 공통점)
예상 포지션
AI Engineer (LLM Application), Backend Engineer (AI Platform), Solution Engineer
인터뷰 질문
RAG 파이프라인 설계 경험, 한국어 문서 처리 노하우, 고객사 요구를 기술로 푸는 사고방식, LLM 평가 방법론
준비 포인트
Phase 2 주제를 "한국어 법령·규정 QA"로 하면 도메인이 정확히 겹침. 솔라 모델을 프로젝트에서 실제로 써보고 사용기를 블로그로 남기면 강력한 신호.
리스크·체크
B2B 특성상 고객사 프로젝트(SI성 업무) 비중이 팀마다 다름 → 커피챗에서 "제품 조직 vs 딜리버리 조직" 구분을 반드시 확인.
②

뤼튼테크놀로지스 (Wrtn)

왜 나에게 맞나

예상 포지션

인터뷰 질문
대규모 트래픽 처리, LLM 비용 최적화(B2C는 토큰 비용이 사활 문제), 멀티 모델 라우팅, 속도감 있는 실행 경험
준비 포인트
Phase 2에서 "토큰 비용 대시보드 + 모델 라우팅(싼 모델·비싼 모델 분기)"을 구현하면 뤼튼 인터뷰에 정확히 꽂힘.
리스크·체크
B2C 회사 특성상 시장 변동에 민감. 지원 시점에 최근 투자·실적 뉴스 확인 필수.

리스크·체크

프렌들리AI (FriendliAI)
