영역별 핵심엑셀 필기·용어·카테고리 시트 + 보강

데이터 개론1-1 ~ 1-4

분류와 결측·이상치

  • 정형은 질적(명목·서열)과 양적(연속·이산), 반정형은 JSON·XML, 비정형은 텍스트·음성·영상. 빅데이터는 3V(양·속도·다양성)에 정확성·가치를 더해 5V.
  • 결측 유형은 MCAR(완전 무작위) · MAR(관측된 다른 변수에 의존) · MNAR(값 자체에 의존). 결측 자체가 정보일 수 있어 무조건 삭제하는 것은 틀린 선택지다.
  • 대치: 평균·중앙값·최빈값, Hot-deck(현재 표본에서 비슷한 응답), Cold-deck(외부·이전 연구), 회귀, KNN, 다중 대치(MICE). Hot/Cold deck 을 헷갈리지 말 것.
  • 이상치 탐지: IQR(Q1−1.5·IQR, Q3+1.5·IQR), Z-score(|z|>3), ESD, DBSCAN, Isolation Forest, LOF, One-Class SVM, 박스플롯. VIF 는 다중공선성 진단이지 이상치 탐지가 아니다(기출).

변환과 시각화

  • MinMax는 [0,1], Standard는 평균 0·표준편차 1, Robust는 중앙값·IQR 기준. Box-Cox는 양수만, Yeo-Johnson은 음수도 가능. 거듭제곱 변환에서 λ=0 이면 로그.
  • 범주형: One-Hot(k개) · 더미(k−1) · Label · Target · Frequency · Hashing. 회귀에서 더미를 k개 다 넣으면 완전 공선성.
  • 바이올린은 박스플롯+KDE, 줄기-잎은 분포와 값을 함께, 평행좌표는 다차원 패턴·군집, Q-Q plot 은 정규성을 눈으로.

가설검정의 말

  • 1종 오류(α): H0 가 참인데 기각. 2종 오류(β): H0 가 거짓인데 기각 못함. 검정력은 1−β. 표본이 늘면 둘 다 줄어드는 경향.
  • p-value < α 이면 H0 기각. 신뢰수준은 1−α. 정규성 검정의 귀무가설은 「정규분포를 따른다」다.
  • 베이즈: P(A|B) = P(B|A)·P(A) / P(B). 사전확률 · 우도 · 증거 · 사후확률 이름을 매칭할 것.

회귀와 분산분석

  • 가정은 선형성·독립성·등분산·정규성, 거기에 독립변수 간 다중공선성 없음. 진단은 VIF(통상 10 초과면 의심), 상관행렬.
  • SST = SSR + SSE, R² = SSR/SST = 1 − SSE/SST. 모형 유의성은 F-검정. 영향점은 레버리지 · Cook's distance · DFFITS · DFBETAS.
  • AIC = −2lnL + 2p, BIC = −2lnL + p·ln n — 낮을수록 좋고 BIC 가 표본 수까지 벌점. 변수 선택은 전진·후진·단계적이며 PCA 는 변수 선택이 아니다. Mallow's Cp 는 p+1 에 가까운 것.
  • 오즈 = p/(1−p), 오즈비 = exp(β). 로지스틱 회귀의 계수 해석은 한 단위 증가 시 오즈가 exp(β)배.
  • ANOVA 는 정규·등분산·독립. 표본 수가 같을 필요는 없다. 요인이 둘이면 이원분산분석, 요인의 효과가 다른 요인의 수준에 따라 달라지면 교호작용(교호항마다 관측 2개 이상). 사후검정은 Tukey HSD 등.
머신러닝 일반3-1 ~ 3-4
  • 모수 모델은 분포·함수형을 가정하고 계수를 학습(선형·로지스틱·신경망), 비모수 모델은 가정 없이 데이터로(결정트리·KNN).
  • 일반화가 목표다. 과대적합 대응: 규제(L1·L2), 조기 종료, 드롭아웃, 데이터 증가, 앙상블, 교차검증, 변수 축소.
  • 검증: hold-out · K-fold · Stratified(타깃 분포 유지) · Group(학습에 없는 범주를 평가에) · 시계열(T 이전 학습, T 이후 평가) · LOOCV. 데이터가 적고 정밀한 검증이 필요하면 교차검증.
  • 하이퍼파라미터는 그리드·랜덤·베이지안 탐색, 매개변수는 경사하강법으로. 학습률이 크면 발산, 작으면 느림.
  • 차원의 저주: 차원이 늘면 데이터가 희소해지고 거리의 변별력이 떨어져 과대적합 위험이 커진다. 대응은 변수 선택·차원축소·규제.
  • 변수 선택 — Filter(통계 특성: 상관·카이제곱·정보이득) · Wrapper(모델로 탐색: RFE·전진·후진·유전알고리즘) · Embedded(모델에 내장: Lasso·Ridge·Elastic Net·트리 중요도).
  • 클래스 불균형 — 언더샘플링(랜덤·Tomek link·CNN·OSS), 오버샘플링(랜덤·SMOTE·Borderline·ADASYN), 비용 함수(소수 클래스 손실 가중치를 더 크게), 임계값 이동, 앙상블. SMOTE 는 소수 클래스 이웃 사이를 선형 보간해 합성하며 클래스 수를 정확히 맞추는 것은 아니다. MCMC 는 불균형과 무관.
지도학습4-1 ~ 4-5
  • Ridge(L2)는 계수를 줄이지만 0 으로 만들지 않고 닫힌 해가 있다. Lasso(L1)는 일부 계수를 정확히 0 으로 만들어 변수 선택 효과가 있고 닫힌 해가 없다(좌표하강). Elastic Net은 둘의 혼합. 람다가 클수록 규제가 강하다.
  • GLM: 반응변수 분포에 맞는 연결함수 — 이항은 logit(로지스틱 회귀), 푸아송은 log. 종속변수의 정규성이 없어도 쓴다.
  • 결정트리: 지니 = 1 − Σp², 엔트로피 = −Σp·log p, 정보이득이 큰 분할. 깊이를 키우면 과대적합 → 가지치기. 스케일링 불필요.
  • 나이브 베이즈는 특징 간 조건부 독립 가정, 라플라스 스무딩. KNN은 지도학습이며 학습이 없는 lazy 모델, K 가 작으면 과대적합, 스케일링 필수.
  • SVM: 마진 최대화, 서포트 벡터만 결정에 관여. C 가 크면 마진이 좁고 과대적합, 비선형은 커널 트릭(RBF·poly)으로 고차원 매핑 없이 계산. 스케일링 필수.
  • 배깅: 부트스트랩 표본으로 병렬 학습해 분산을 줄임. 랜덤 포레스트는 배깅 + 노드마다 변수 무작위 선택, 분류와 회귀(트리 예측 평균) 모두 가능, OOB 평가.
  • 부스팅: 순차 학습으로 편향을 줄임. AdaBoost는 이전 모델이 틀린 샘플의 가중치를 올리고, 약한 학습기는 「랜덤보다 약간 나은」 모델이며 신뢰도로 가중합한다. Gradient Boosting은 잔차(손실의 음의 기울기)에 다음 트리를 맞춘다. XGBoost는 정규화·2차 근사·subsample·colsample 을 더한 것.
  • Voting은 hard(다수결)·soft(확률 평균), Stacking 은 메타 모델.

연관규칙

  • 지지도 = P(A∩B), 신뢰도 = P(B|A), 향상도 = P(B|A)/P(B). 향상도 >1 양의 관계, =1 독립, <1 음의 관계. Apriori · FP-Growth.
비지도학습5-1 ~ 5-3
  • K-means: SSE(distortion)는 반복마다 증가하지 않고 수렴하지만 초기값에 따라 결과가 달라진다(K-means++). 구형·비슷한 크기·비슷한 밀도를 가정해 이상치·밀도 차·비볼록 군집에 약하다.
  • K-medoids는 중심을 실제 데이터 점으로 잡아 이상치에 강건하다.
  • 계층적 군집: 단일(최단) 연결은 사슬 효과, 완전(최장) 연결은 지름이 작은 군집, 평균 연결, 중심 연결, Ward(분산 증가 최소). 덴드로그램을 자르는 높이로 군집 수 결정.
  • DBSCAN: eps 와 min_samples 두 개, 핵심·경계·잡음 점. 군집 수를 정하지 않아도 되고 비구형도 찾으며 잡음을 분리한다. 밀도 차가 큰 데이터에는 약하다.
  • 평가: 실루엣(−1~1, 클수록 좋음), Dunn(군집 간 최소거리 / 군집 내 최대거리), Davies-Bouldin(낮을수록 좋음), elbow.
  • 차원축소: PCA(분산 최대 축, 비지도, 스케일링 필요) · 요인분석(잠재요인, 개수는 분석 중 결정, 요인은 대등) · LDA(지도, 클래스 간 분산 / 클래스 내 분산 최대화) · MDS(거리 보존) · t-SNE(시각화용, 비선형) · SVD · PLS.
  • 이상탐지: Isolation Forest 는 무작위 분할로 한 점이 고립되는 경로가 짧을수록 이상치(비지도·앙상블). LOF 는 이웃 대비 밀도. One-Class SVM, Autoencoder 재구성 오차.
딥러닝 (필기만)6-1 ~ 6-3
  • 단일 퍼셉트론은 선형 분리만(XOR 불가). 3클래스 이상은 다층 퍼셉트론·RNN·CNN 에 softmax 를 쓰면 가능하고, 오토인코더는 분류 모델이 아니다.
  • 활성화: 비선형 활성화가 없으면 층을 쌓아도 하나의 선형 변환이다(그래서 쓴다). sigmoid·tanh 는 기울기 소실, ReLU 는 dying ReLU. 출력층은 이진 sigmoid, 다중 softmax — ReLU 는 부적절. 다중 분류 라벨은 원-핫.
  • 학습: 역전파, 경사하강법(SGD·Momentum·RMSProp·Adam). 과대적합 방지는 규제·드롭아웃·배치 정규화·조기 종료·Max pooling. 기울기 소실은 역전파에서 기울기가 매우 작아지는 현상.
  • CNN: 합성곱·풀링. 출력 크기 = ⌊(W − K + 2P) / S⌋ + 1.
  • RNN: 시퀀스, 긴 의존성은 LSTM(게이트)·GRU 로. Autoencoder: 인코더–디코더, 차원축소·잡음 제거·이상탐지.

출제 빈도샘플 8세트의 소문항 268칸에서 키워드 집계

막대는 8개 샘플 세트 중 몇 세트에 나왔는지, 오른쪽 숫자는 소문항 칸에서 등장한 횟수. 8세트는 제조 공정 · 전자제품 구매 · 페이먼트 앱 · 스마트폰 센서 · 스마트폰 만족도 · 스마트팩토리 · 태양광 · 조리 품질. 키워드 일치로 센 것이라 한 칸이 두 항목에 걸릴 수 있다.

읽는 법. 데이터 분할·정규화·선형회귀는 8세트 모두에 있다. 문제 하나하나는 전처리(분할·결측·스케일링)가 앞에 깔리고 뒤에 모델·검정이 붙는 구조라, 전처리가 틀리면 뒤가 전부 틀린다. 「계산」은 라이브러리 호출이 아니라 식을 직접 쓰는 문항(신뢰구간·거리·지표)이다.

def dunn(X, lab):                                     # 군집 간 최소거리 / 군집 내 최대거리
    ks = np.unique(lab)
    inter = min(cdist(X[lab == a], X[lab == b]).min() for i, a in enumerate(ks) for b in ks[i+1:])
    intra = max(pdist(X[lab == k]).max() for k in ks if (lab == k).sum() > 1)
    return inter / intra

MAPE비율로 반환(0.5 = 50%). y_true 가 0 이면 아주 큰 값이 나온다.sklearn
RMSEmean_squared_error에 squared 인자가 더는 없다. root_mean_squared_error를 쓰거나 np.sqrt.sklearn
chi2_contingencycorrection=True가 기본이며 자유도가 1(2×2)일 때만 Yates 보정이 적용된다.scipy
levenecenter='median'이 기본(치우친 분포 권장). Bartlett 은 정규성 가정.scipy
